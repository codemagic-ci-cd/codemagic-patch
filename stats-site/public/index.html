Try Patch

Run the real server on your machine, reach it from your phone through ngrok, and ship an update to your own app.

Source

The SDKs and the CLI are Apache 2.0. The server and dashboard are source-available under the Codemagic Server License, free to self-host up to 1M MAU.

GitHub · codemagic-ci-cd/codemagic-patch (opens in a new tab)

Run it with ngrok

Terminal 
npm install -g @codemagic/patch-cli
cmpatch selfhost install --ngrok

Installs the server, with sign-in, on this machine and makes it reachable from any phone at the free https:// address your ngrok account comes with. Needs Docker, a free ngrok account, and a GitHub, Bitbucket, or GitLab account to sign in with. No domain, DNS records, or open ports.
