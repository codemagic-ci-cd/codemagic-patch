# Roadmap

This page shows where Patch is heading.

Patch ships JavaScript and web updates to React Native and Capacitor apps without a store release. Most of the work below makes the server easier to run and removes manual steps between a build and a release, for people and for AI agents. Patch will stay focused on the JavaScript and web layer, with a server you can read and run yourself.

To suggest a feature or comment on an item, post in the
[Ideas category](https://github.com/codemagic-ci-cd/codemagic-patch/discussions/categories/ideas)
of GitHub Discussions.

## Building now

{/* Work that has started. Keep to a handful of items. */}

- **Automatic app binary registration.** Your app build records the details Patch uses to match updates to the right binary, so you no longer register each binary by hand. React Native comes first, then Capacitor.
- **Active device counts.** See how many devices used your app each week and each month, on the dashboard and in the CLI.

## Planned

{/* Decided, not started. Priority order. */}

- **Webhooks for releases and rollouts.** Patch sends a message to your systems when a release is published, a rollout changes, or a rollback happens.
- **Large uploads behind a proxy.** Upload large releases even when a proxy such as Cloudflare limits requests to about 100 MB. The CLI sends bundles straight to storage instead of through the server.
- **Smaller first update after install.** A newly installed app downloads only the changes since the bundle shipped inside the app, not the whole bundle. React Native comes first, then Capacitor.
- **Re.Pack support.** Ship updates for apps that use Re.Pack instead of Metro to bundle their JavaScript.
- **React Native inside native apps.** Ship updates to React Native screens that live inside an existing native iOS or Android app.
- **Self-host on Cloudflare Containers.** Run the Patch server on Cloudflare Containers with R2 storage, without managing a VM.
