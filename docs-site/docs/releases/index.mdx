# Release Notes

Patch has five surfaces, each released as its own package with its own version
and tag. Each surface has a page with its full notes. This page lists releases
across all surfaces, newest first, and the version requirements between them.
Shorter summaries and install links are on [GitHub Releases](https://github.com/codemagic-ci-cd/codemagic-patch/releases).

| Surface | Notes | Latest | Upgrade |
| --- | --- | --- | --- |
| React Native SDK | [React Native](/docs/releases/react-native) | 0.5.0 | `npm install @codemagic/react-native-patch@latest` |
| CLI (`cmpatch`) | [CLI](/docs/releases/cli) | 0.6.0 | `npm install -g @codemagic/patch-cli@latest` |
| Server and dashboard | [Server](/docs/releases/server) | 0.6.0 | [`cmpatch selfhost upgrade`](/docs/reference/cli-reference#self-hosting) |

| CLI for Capacitor (`cmpatch-capacitor`) | [CLI for Capacitor](/docs/releases/capacitor-cli) | 0.1.0 | `npm install -g @codemagic/capacitor-patch-cli@latest` |

## Upgrade order and compatibility

Surfaces are versioned independently. A newer server accepts requests from
older SDKs and CLIs, so upgrading the server does not break apps already in the
field. An older server is not guaranteed to work with a newer SDK or CLI. If an
SDK or CLI version needs a newer server, its entry says so at the top, and the
table below lists those requirements.

Upgrade the server first, then the CLI, then ship app builds with the new SDK.
Each server entry starts with an upgrade impact section that lists migrations,
configuration changes, and service restarts.

| Version | Needs | Why |
| --- | --- | --- |
| React Native SDK [0.5.0](/docs/releases/react-native#v0-5-0) | Server 0.5.0 or newer | Reports update lifecycle as `Ready` and `Applied`; older servers drop those events. |
| CLI for Capacitor [0.1.0](/docs/releases/capacitor-cli#v0-1-0) | Server 0.6.0 or newer | Sets the app framework, which older servers do not store; the dashboard then treats the app as a React Native app. |

## What shipped

### 6th October 2026

- **Capacitor SDK [0.1.0](/docs/releases/capacitor-sdk#v0-1-0):** First
  published version. OTA updates for the web assets of Capacitor and Ionic
  apps, using the same protocol and server as the React Native SDK.
- **CLI for Capacitor [0.1.0](/docs/releases/capacitor-cli#v0-1-0):** First
  published version. `cmpatch-capacitor` publishes and manages releases for
  Capacitor apps. Requires server 0.6.0.
- **Server [0.6.0](/docs/releases/server#v0-6-0):** Stores each app's
  framework and shows framework-specific commands in the dashboard; binary
  version filter for deployment adoption and release history; full bundle and
  diff download sizes on release detail; migration `0017` adds a column to
  `app`.
- **CLI [0.6.0](/docs/releases/cli#v0-6-0):** App lists, pickers, `init`, and
  `doctor` show React Native apps only; Capacitor apps are managed with
  `cmpatch-capacitor`.

### 2nd October 2026

- **Server [0.5.1](/docs/releases/server#v0-5-1):** The bundled MinIO images
  are no longer available to pull, so the stack now uses PGSTY Silo images.
  Backups restart only the server service.
