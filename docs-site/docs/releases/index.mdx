# Release Notes

Patch has five surfaces, each released as its own package with its own version
and tag. Each surface has a page with its full notes. This page lists releases
across all surfaces, newest first. Shorter summaries and install links are on
[GitHub Releases](https://github.com/codemagic-ci-cd/codemagic-patch/releases).
For planned work, see the [Roadmap](/docs/roadmap).

| Surface | Notes | Latest | Upgrade |
| --- | --- | --- | --- |
| React Native SDK | [React Native](/docs/releases/react-native) | 0.7.0 | `npm install @codemagic/react-native-patch@latest` |
| CLI (`cmpatch`) | [CLI](/docs/releases/cli) | 0.10.0 | `npm install -g @codemagic/patch-cli@latest` |
| Server and dashboard | [Server](/docs/releases/server) | 0.10.0 | [`cmpatch selfhost upgrade`](/docs/reference/cli-reference#self-hosting) |

## Compatibility {#upgrade-order-and-compatibility}

A newer server works with older SDKs and CLIs, so apps on an older SDK keep
working after you upgrade the server. The reverse is not guaranteed.

## What shipped

### 17th November 2026

- **Server [0.10.0](/docs/releases/server#v0-10-0)**
  - **API tokens can no longer grant access:** Creating tokens, adding or
    inviting members, changing roles, and transferring apps need a browser
    sign-in, so a leaked token cannot leave access behind (breaking for
    CI that does these with a token)
  - **Install without building:** `selfhost install` and `upgrade` pull a
    published x86 and ARM server image instead of building on your
    server. Update `cmpatch` before you upgrade
  - **Sign out everywhere:** End every session and delete every API token
    on your account from the dashboard. Sign-ins last at most 90 days
  - **Rotate a service account's token:** From the Members page or with
    `cmpatch member rotate-token`
- **CLI [0.10.0](/docs/releases/cli#v0-10-0)**
  - **Upgrade asks first:** `selfhost upgrade` shows its plan and asks
    before it runs. Scripts need `--yes` (breaking for scripts). A
    database newer than the release is refused before anything changes
- **React Native SDK [0.7.0](/docs/releases/react-native#v0-7-0)**
  - **React Native SwiftPM mode:** The package ships a `Package.swift`,
    so apps on React Native 0.88 or later can link the SDK as a Swift
    package instead of a pod. `cmpatch wire` in CLI 0.10.0 sets them up
    without `pod install`
  - **Android restart crash on Expo SDK 58 fixed:** Applying an update no
    longer crashes with a missing `ExpoApplication` error
- **CLI for Capacitor [0.3.1](/docs/releases/capacitor-cli#v0-3-1)**
  - **Range totals in the CLI:** `deployment timeseries` prints the
    range's totals and success rate. Requires server 0.10.0

### 3rd November 2026

- **Server [0.9.0](/docs/releases/server#v0-9-0)**
  - **Usage report, opt-out available:** Daily anonymous aggregate counts
    go to Codemagic for public statistics only, never the licence MAU
    limit. On by default; `SERVER_TELEMETRY=false` turns it off
  - **Update-check config fixed:** `SERVER_UPDATE_CHECK=false`
    in `.env.selfhost` now disables the GitHub release lookup; Compose
    used to ignore it
- **CLI [0.9.0](/docs/releases/cli#v0-9-0)**
  - **Install with your own Postgres:** Point `selfhost install` at a
    database you already run (`--database-url`) for backups and
    point-in-time recovery; it checks connectivity from the server
    before writing anything
  - **Promotion and rollout in CLI:** `release promote` picks deployments
    from a list, and both it and `release-react` ask for the rollout
    percentage instead of silently using 100%

### 28th October 2026

- **Server [0.8.0](/docs/releases/server#v0-8-0)**
  - **Slower Postgres growth:** Raw events stay 8 days, then fold into
    daily totals kept indefinitely, so charts stay accurate. The upgrade
    builds a metrics index first; ingest waits for it
- **CLI [0.8.0](/docs/releases/cli#v0-8-0)**
  - **Install on Fly.io:** `selfhost install --fly` deploys Patch with
    Tigris storage, without a VPS, DNS, or certificates; `upgrade`,
    `backup`, and `restore` work on that install
  - **Try on a real device without a domain:** `selfhost install --ngrok`
    runs the stack on this machine behind an ngrok address
- **React Native SDK [0.6.0](/docs/releases/react-native#v0-6-0)**
  - **Test without a native binary:** Jest and Vitest fakes (`/jest`,
    `/vitest`) so suites can run in CI
  - **Background boots no longer burn a launch:** Android background
    boots no longer count toward crash rollback
  - **Fewer launch attempts before rollback:** Default lowered from 3 to
    2
- **Capacitor SDK [0.1.2](/docs/releases/capacitor-sdk#v0-1-2)**
  - **Fewer launch attempts before rollback:** Default lowered from 3 to
    2
- **CLI for Capacitor [0.3.0](/docs/releases/capacitor-cli#v0-3-0)**
  - **Token revoke confirms:** Confirms before it runs, unless `--yes`
    (breaking for scripts)
  - **Metrics from the CLI:** Deployment timeseries and failure
    drill-down, matching the dashboard

### 19th October 2026

- **Server [0.7.0](/docs/releases/server#v0-7-0)**
  - **Charts fetch one range:** Deployment and release pages fetch only
    the selected range instead of all four
  - **Do not roll back the image alone:** Migration `0018` drops an
    unused column; an older image after upgrade breaks metrics ingest.
    Restore the pre-upgrade backup instead
- **CLI [0.7.0](/docs/releases/cli#v0-7-0)**
  - **Destructive member and token commands confirm:** `member remove`,
    `member update`, `member invite-revoke`, and `token revoke` ask
    before changing access, unless `--yes` (breaking for scripts)
  - **Manage teams and the host from the CLI:** `server status`,
    `team list` / `show`, and `app transfer`
  - **Metrics from the CLI:** Deployment timeseries and failure
    drill-down
- **React Native SDK [0.5.1](/docs/releases/react-native#v0-5-1)**
  - **Newer React Native and Expo:** React Native 0.88 and Expo SDK 58
  - **Stalled metrics no longer block updates:** Uploads that hang no
    longer block update checks, downloads, or other SDK calls
- **Capacitor SDK [0.1.1](/docs/releases/capacitor-sdk#v0-1-1)**
  - **Stalled metrics no longer block updates:** Uploads that hang no
    longer block plugin calls or update downloads
- **CLI for Capacitor [0.2.0](/docs/releases/capacitor-cli#v0-2-0)**
  - **JSON when piped:** Stdout is JSON when piped (breaking for scripts
    that read text)
  - **Doctor for Capacitor:** `cmpatch-capacitor doctor` checks the SDK
    setup

### 6th October 2026

- **Capacitor SDK [0.1.0](/docs/releases/capacitor-sdk#v0-1-0)**
  - **OTA for Capacitor and Ionic:** First published version. Web-asset
    updates on the same protocol and server as the React Native SDK
- **CLI for Capacitor [0.1.0](/docs/releases/capacitor-cli#v0-1-0)**

    `cmpatch-capacitor` manages Capacitor releases. Requires server

- **Server [0.6.0](/docs/releases/server#v0-6-0)**

    right flow
  - **Filter adoption by binary version:** Focus charts and release
    history on one version or group
- **CLI [0.6.0](/docs/releases/cli#v0-6-0)**
  - **React Native only in `cmpatch`:** App lists, pickers, `init`, and
    `doctor` hide Capacitor apps; manage those with `cmpatch-capacitor`

### 2nd October 2026

- **Server [0.5.1](/docs/releases/server#v0-5-1)**
  - **Silo replaces MinIO images:** Bundled object storage switches to
    PGSTY Silo, because the old MinIO images are gone
