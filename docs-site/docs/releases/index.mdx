# Release Notes

Patch has five surfaces, each released as its own package with its own version
and tag. Each surface has a page with its full notes. This page lists releases
across all surfaces, newest first. Shorter summaries and install links are on
[GitHub Releases](https://github.com/codemagic-ci-cd/codemagic-patch/releases).
For planned work, see the [Roadmap](/docs/roadmap).

| Surface | Notes | Latest | Upgrade |
| --- | --- | --- | --- |
| React Native SDK | [React Native](/docs/releases/react-native) | 0.8.0 | `npm install @codemagic/react-native-patch@latest` |
| CLI (`cmpatch`) | [CLI](/docs/releases/cli) | 0.11.0 | `npm install -g @codemagic/patch-cli@latest` |
| Server and dashboard | [Server](/docs/releases/server) | 0.11.0 | [`cmpatch selfhost upgrade`](/docs/reference/cli-reference#self-hosting) |

## Compatibility {#upgrade-order-and-compatibility}

A newer server works with older SDKs and CLIs, so apps on an older SDK keep
working after you upgrade the server. The reverse is not guaranteed.

## What shipped

### 19th November 2026

- **Server [0.11.0](/docs/releases/server#v0-11-0)**
  - Adds webhooks: the server sends a signed `POST` to your URL when a release
    goes live, changes, or fails. Manage them on the dashboard or with
    `cmpatch webhook`
  - `POST /v1/teams` accepts an `owner`, also from an API token
- **CLI [0.11.0](/docs/releases/cli#v0-11-0)**
  - Adds `cmpatch fingerprint --artifact`, which prints the fingerprint,
    bundle hash, and binary version of an `.ipa`, `.xcarchive`, `.apk`, or
    `.aab`
  - Prints a notice when a newer `cmpatch` is on npm.
    `CMPATCH_NO_UPDATE_CHECK=1` turns it off
- **React Native SDK [0.8.0](/docs/releases/react-native#v0-8-0)**
  - Records the native fingerprint and bundle hash in every build. After
    upgrading, run `cmpatch wire` again and ship a new binary version
- **CLI for Capacitor [0.4.0](/docs/releases/capacitor-cli#v0-4-0)**
  - Prints a notice when a newer `cmpatch-capacitor` is on npm.
    `CMPATCH_NO_UPDATE_CHECK=1` turns it off

### 17th November 2026

- **Server [0.10.0](/docs/releases/server#v0-10-0)**
  - API tokens can no longer grant access. Creating tokens, adding or
    inviting members, changing roles, and transferring apps need a browser
    sign-in (breaking for CI that does these with a token)
  - `selfhost install` and `upgrade` pull a published x86 and ARM server
    image instead of building on your server. Update `cmpatch` before you
    upgrade
  - Adds sign out everywhere: the dashboard ends every session and deletes
    every API token on your account. Sign-ins last at most 90 days
  - Adds service account token rotation, from the Members page or with
    `cmpatch member rotate-token`
- **CLI [0.10.0](/docs/releases/cli#v0-10-0)**
  - `selfhost upgrade` shows its plan and asks before it runs, so scripts
    need `--yes` (breaking for scripts). It refuses a database newer than
    the release before anything changes
- **React Native SDK [0.7.0](/docs/releases/react-native#v0-7-0)**
  - Adds SwiftPM mode: the package ships a `Package.swift`, so apps on
    React Native 0.88 or later can link the SDK as a Swift package instead
    of a pod. `cmpatch wire` in CLI 0.10.0 sets them up without
    `pod install`
  - Fixes an Android crash with a missing `ExpoApplication` error when an
    update is applied on Expo SDK 58
- **CLI for Capacitor [0.3.1](/docs/releases/capacitor-cli#v0-3-1)**
  - `deployment timeseries` prints the range's totals and success rate.
    Requires server 0.10.0

### 3rd November 2026

- **Server [0.9.0](/docs/releases/server#v0-9-0)**
  - Adds a daily usage report: anonymous aggregate counts go to Codemagic
    for public statistics only, never the licence MAU limit. On by default;
    `SERVER_TELEMETRY=false` turns it off
  - Fixes `SERVER_UPDATE_CHECK=false` in `.env.selfhost`, which Compose
    ignored. It now disables the GitHub release lookup
- **CLI [0.9.0](/docs/releases/cli#v0-9-0)**
  - `selfhost install --database-url` installs against a Postgres you
    already run, for backups and point-in-time recovery. It checks
    connectivity from the server before writing anything
  - `release promote` picks deployments from a list. It and
    `release-react` ask for the rollout percentage instead of silently
    using 100%

### 28th October 2026

- **Server [0.8.0](/docs/releases/server#v0-8-0)**
  - Keeps raw events 8 days, then folds them into daily totals kept
    indefinitely, so Postgres grows slower and charts stay accurate. The
    upgrade builds a metrics index first; ingest waits for it
- **CLI [0.8.0](/docs/releases/cli#v0-8-0)**
  - Adds `selfhost install --fly`, which deploys Patch on Fly.io with
    Tigris storage, without a VPS, DNS, or certificates. `upgrade`,
    `backup`, and `restore` work on that install
  - Adds `selfhost install --ngrok`, which runs the stack on this machine
    behind an ngrok address, for trying Patch on a real device without a
    domain
- **React Native SDK [0.6.0](/docs/releases/react-native#v0-6-0)**
  - Adds Jest and Vitest fakes (`/jest`, `/vitest`) for running suites in
    CI without a native binary
  - Android background boots no longer count as launches toward crash
    rollback
  - Lowers the default launch attempts before rollback from 3 to 2
- **Capacitor SDK [0.1.2](/docs/releases/capacitor-sdk#v0-1-2)**
  - Lowers the default launch attempts before rollback from 3 to 2
- **CLI for Capacitor [0.3.0](/docs/releases/capacitor-cli#v0-3-0)**
  - `token revoke` confirms before it runs, unless `--yes` (breaking for
    scripts)
  - Adds deployment timeseries and failure drill-down, matching the
    dashboard

### 19th October 2026

- **Server [0.7.0](/docs/releases/server#v0-7-0)**
  - Deployment and release pages fetch only the selected chart range
    instead of all four
  - Migration `0018` drops an unused column, so an older image after the
    upgrade breaks metrics ingest. Do not roll back the image alone;
    restore the pre-upgrade backup instead
- **CLI [0.7.0](/docs/releases/cli#v0-7-0)**
  - `member remove`, `member update`, `member invite-revoke`, and
    `token revoke` ask before changing access, unless `--yes` (breaking for
    scripts)
  - Adds `server status`, `team list` / `show`, and `app transfer`
  - Adds deployment timeseries and failure drill-down
- **React Native SDK [0.5.1](/docs/releases/react-native#v0-5-1)**
  - Supports React Native 0.88 and Expo SDK 58
  - Metrics uploads that hang no longer block update checks, downloads, or
    other SDK calls
- **Capacitor SDK [0.1.1](/docs/releases/capacitor-sdk#v0-1-1)**
  - Metrics uploads that hang no longer block plugin calls or update
    downloads
- **CLI for Capacitor [0.2.0](/docs/releases/capacitor-cli#v0-2-0)**
  - Stdout is JSON when piped (breaking for scripts that read text)
  - Adds `cmpatch-capacitor doctor`, which checks the SDK setup

### 6th October 2026

- **Capacitor SDK [0.1.0](/docs/releases/capacitor-sdk#v0-1-0)**
  - First published version: OTA web-asset updates for Capacitor and
    Ionic, on the same protocol and server as the React Native SDK
- **CLI for Capacitor [0.1.0](/docs/releases/capacitor-cli#v0-1-0)**
  - First published version: `cmpatch-capacitor` publishes and manages
    Capacitor releases. Requires server 0.6.0
- **Server [0.6.0](/docs/releases/server#v0-6-0)**
  - Stores each app's framework and shows the matching release commands
    for Capacitor or React Native
  - Adds a binary version filter for adoption charts and release history,
    by one version or group
- **CLI [0.6.0](/docs/releases/cli#v0-6-0)**
  - App lists, pickers, `init`, and `doctor` hide Capacitor apps, so
    `cmpatch` covers React Native only. Manage Capacitor apps with
    `cmpatch-capacitor`

### 2nd October 2026

- **Server [0.5.1](/docs/releases/server#v0-5-1)**
  - Bundled object storage switches from MinIO to PGSTY Silo, because the
    old MinIO images are gone
