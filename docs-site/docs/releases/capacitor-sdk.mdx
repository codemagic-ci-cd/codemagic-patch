# Capacitor SDK release notes

Release notes for `@codemagic/capacitor-patch`, the client SDK for Capacitor,
Ionic, and Cordova-on-Capacitor apps. Releases for these apps are published
with the [CLI for Capacitor](/docs/releases/capacitor-cli). The other
surfaces' releases and the compatibility table are on the
[Release Notes](/docs/releases) page.

```bash
npm install @codemagic/capacitor-patch@latest
```

Reference: [Native setup for Capacitor](/docs/setup/native-setup-capacitor) ·
[SDK reference](/docs/reference/sdk-reference) ·
[GitHub releases](https://github.com/codemagic-ci-cd/codemagic-patch/releases?q=capacitor-patch%40)

## 0.1.2 {#v0-1-2}

*28th October 2026*

### Fixes

- **Resource shrinking keeps the native overrides:** Android release builds
  with resource shrinking no longer remove the `CodemagicPatch*` overrides in
  `strings.xml`, so the app no longer falls back to `capacitor.config.ts`. On
  older SDKs, see
  [Release published but app finds no update](/docs/troubleshooting#release-published-but-app-finds-no-update).

### Other changes

- **Default launch attempts lowered to 2:** `maxLaunchAttempts` defaults to 2 on
  Android and iOS, so a broken package rolls back on its third launch instead
  of its fourth. Set the value explicitly to keep 3.

See the [SDK release](https://github.com/codemagic-ci-cd/codemagic-patch/releases/tag/%40codemagic/capacitor-patch%400.1.2).

## 0.1.1 {#v0-1-1}

*19th October 2026*

### Fixes

- **Metrics uploads no longer block plugin calls:** A metrics upload stuck on
  a slow or unresponsive network no longer holds up Capacitor plugin calls,
  manifest fetches, or update downloads. Metrics are now processed separately
  from other SDK operations.

### Other changes

- **`sdk_version` removed from metrics events:** The SDK no longer sends the
  unused `sdk_version` field. Servers still accept it from older SDKs.

See the [SDK release](https://github.com/codemagic-ci-cd/codemagic-patch/releases/tag/%40codemagic/capacitor-patch%400.1.1).

## 0.1.0 {#v0-1-0}

*6th October 2026*

First published version. The API may still change before 1.0.

The SDK applies over-the-air updates to the web assets of a Capacitor, Ionic,
or Cordova-on-Capacitor app. It uses the same protocol and server as the React
Native SDK. A release is a directory of web assets; applying it points the
WebView at that directory with Capacitor's `setServerBasePath`. There is no
bundler integration and no native fingerprint; releases are scoped by the
native app version. To set it up, install the package, run `npx cap sync`, and
follow [Native setup for Capacitor](/docs/setup/native-setup-capacitor).

See the [SDK release](https://github.com/codemagic-ci-cd/codemagic-patch/releases/tag/%40codemagic/capacitor-patch%400.1.0).
