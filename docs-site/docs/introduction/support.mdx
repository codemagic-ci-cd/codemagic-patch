# Support

Patch is created by Codemagic, and has a full team behind it. Use the following options if you need support.

## Discord

Join the [Codemagic Discord](https://codemagic.io/discord/), which has a dedicated channel for Patch. The developers behind Patch will be available to answer any questions.

## GitHub

To report a bug or request a change, [open a GitHub issue](https://github.com/codemagic-ci-cd/codemagic-patch/issues).

Contributions are also very welcome if you come across a detail you want to fix. Please go ahead and create a PR.

For what shipped in each release, see [Releases](/docs/releases).
